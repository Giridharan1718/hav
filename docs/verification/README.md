# Historical verification records

Files in this directory are phase reports and evidence captured during development.
They are retained for traceability, but they are **not** the current verification
record.

The authoritative report is [`../verification-report.md`](../verification-report.md).
Some older reports contain pre-fix counts (for example, 109 backend tests) or superseded
configuration experiments (for example, a temporary Docker host-port change to `55433`
that was reverted). Use the authoritative report and
[`evidence/pytest-110.txt`](evidence/pytest-110.txt) for current results.

Current evidence logs are in [`evidence/`](evidence/).
